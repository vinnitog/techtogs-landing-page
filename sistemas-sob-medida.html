PROJETO REAL EM MARÍLIA

Tecnologia criada para a BRD Advogados.

Para o escritório BRD Advogados, em Marília (SP), a TechTogs desenvolveu soluções diferentes para atividades jurídicas e administrativas. Cada produto foi pensado para uma rotina específica.

APLICAÇÃO EM PRODUÇÃO

BRD Assistant

Assistente interno para apoiar tarefas recorrentes dos advogados e a criação de documentos. A aplicação possui acesso autenticado e base de dados própria.

DEMONSTRAÇÃO

BRD Concordia

Interface demonstrativa para consultar débitos, acordos e prazos ligados à recuperação de crédito. Os registros apresentados são fictícios.

PROTÓTIPO

BRD Pactum

Protótipo para cadastro de partes, elaboração e acompanhamento de contratos, agenda de vencimentos e indicadores. A versão publicada usa dados de demonstração.

Os três sistemas têm estágios diferentes. Não apresentamos os protótipos como ferramentas em operação nem atribuímos ganhos numéricos sem medição.

COMO TRABALHAMOS

Começamos pelo que precisa funcionar melhor.

Entendemos quem usa a ferramenta, quais informações entram em cada etapa e qual decisão a equipe precisa tomar. Depois desenhamos um primeiro recorte do sistema, construímos, validamos com os usuários e ajustamos o que for necessário.

O projeto pode começar com um fluxo pequeno, como organizar clientes e pedidos, e ganhar novos módulos conforme a operação pedir.

DÚVIDAS FREQUENTES

Antes de começar.

Preciso ter o sistema todo definido?

Não. A primeira conversa serve para entender o problema, os usuários e as prioridades. O escopo é definido a partir disso.

Um sistema sob medida substitui tudo o que já uso?

Depende do processo. Podemos avaliar o que deve continuar, o que precisa ser conectado e o que faz sentido construir. Integrações dependem das ferramentas envolvidas.

Vocês atendem empresas fora de Marília?

Sim. Atendemos remotamente empresas de todo o Brasil.

Como é definido o investimento?

O custo depende das funcionalidades, integrações e etapas do projeto. Depois de entender o cenário, organizamos um escopo para conversar sobre prioridades e orçamento.
