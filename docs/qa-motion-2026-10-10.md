com as alterações do checkout original preservadas. Biblioteca compartilhada

`qa-senior`, `qa-automate`, Impeccable e acessibilidade.

## Alteração

As interações usam somente opacidade e transforms CSS. O import de `animate`
passou a `motion/mini`, mantendo `hover` de Motion e a sequência de GSAP.
Transforms completos substituem os atalhos de x/y/scale/rotate que exigiam o
motor híbrido; duração, curvas, amplitude e conteúdo permanecem iguais.
O hover também respeita a preferência por movimento reduzido quando acionado.
O [animate oficial](https://motion.dev/docs/animate) documenta a distinção entre
o motor mini para estilos e o híbrido para transforms independentes.

Nenhuma biblioteca de runtime foi adicionada ou atualizada. Playwright 1.62.1
foi adicionado somente ao desenvolvimento para regressões reais de navegador;
seu navegador não integra o bundle. O novo workflow de QA não tem deploy,
credenciais de e-mail ou etapas de modelo pago.

## Medição

`node scripts/measure-motion.mjs b1394d4` compila antes/depois com o mesmo
lockfile, esbuild 0.28.2, minificação, alvo ES2022 e Node 24.12.0. A fonte anterior
é lida do Git sem trocar refs ou gravar arquivos. gzip é calculado localmente.

| Pacote de animações | Antes (bytes) | Depois (bytes) | gzip antes/depois |
| --- | ---: | ---: | ---: |
| Motion | 56.658 | 11.638 | 20.906 / 4.581 |
| GSAP | 115.739 | 115.739 | 45.638 / 45.638 |
| Motion + GSAP, usado em `/` | 172.585 | 127.451 | 66.241 / 50.016 |

A versão principal economiza 45.134 bytes minificados (26,2%) ou 16.225 bytes
no gzip local (24,5%). Estes valores são do pacote de animações, não da página
inteira nem de uma transferência medida em produção. Imagens, fontes, CSS e
tempo de rede/CPU não foram incluídos; não se afirma ganho em Core Web Vitals.
