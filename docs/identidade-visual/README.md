# Identidade visual da TechTogs

Este diretório contém as duas cópias integrais fornecidas pelo proprietário em 29/09/2026. Elas são a referência do projeto para decisões visuais da landing page:

- [`TechTogs-Design-System.md`](TechTogs-Design-System.md): especificações, tokens, padrões de componentes, responsividade, movimento e acessibilidade.
- [`TechTogs-Design-System.html`](TechTogs-Design-System.html): catálogo navegável com exemplos dos temas claro e escuro. A logo está incorporada no próprio HTML; as fontes online são opcionais.

Interpretação prática: a identidade combina neutros minerais, verde-floresta `#1F3830`, lima `#9FF72F` como acento controlado e geometria inspirada no símbolo da marca. O sistema propõe Space Grotesk para títulos, Inter para corpo, escala de espaçamento de 8 px, componentes com estados explícitos e contraste acessível. Preserve a logo original sem inversão ou distorção.

Os documentos descrevem também arquivos de um pacote maior que não foram fornecidos aqui, como `tokens.css`, `components.css` e `assets/techtogs-original.png`. As referências a esses arquivos são documentação do design system, não dependências já instaladas no projeto. A imagem de marca atualmente usada pela landing page permanece em `assets/techtogs-logo.jpeg`.

Os arquivos permanecem como documentação do repositório. A implementação escura inicial está descrita em `../../DESIGN.md` e usa estas referências como base; novas alterações devem continuar a partir dos tokens e componentes existentes.
