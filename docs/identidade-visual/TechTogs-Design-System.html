Estrutura que acompanha.

Margens de 16 px no celular e 32 px a partir de 640 px. Ultra-wide aumenta respiro; texto corrido preserva a largura de leitura.

Pronto para implementar.

tokens.css + components.css + theme-init.js + components.js. JSON canônico e adaptadores Tailwind v3/v4 incluídos no pacote.
